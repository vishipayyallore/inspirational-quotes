# Chat Abbreviations Guide

A practical guide to common abbreviations used in informal digital communication, especially in tech and professional chats.

| Type       | Abbreviation   | Meaning                              | Example                                  |
| ---------- | -------------- | ------------------------------------ | ---------------------------------------- |
| Chat       | **afaict**     | As far as I can tell                 | "afaict, the API is working fine."       |
| Chat       | **afaik**      | As far as I know                     | "Afaik, the deployment's complete."      |
| Chat       | **brb**        | Be right back                        | "brb, grabbing coffee ☕"                 |
| Chat       | **btw**        | By the way                           | "btw, Raj will join remotely."           |
| Chat       | **fyi**        | For your information                 | "fyi, new build is ready."               |
| Chat       | **idk**        | I don't know                         | "What's the release date?" → "idk 🤔"    |
| Chat       | **iirc**       | If I recall correctly                | "iirc, we fixed that bug last week."     |
| Chat       | **ikr**        | I know, right?                       | "This bug was tricky." → "ikr 😅"        |
| Chat       | **imo / imho** | In my opinion / In my humble opinion | "Imo, we should use microservices here." |
| Chat       | **lmk**        | Let me know                          | "lmk if you're joining the session."     |
| Chat       | **np**         | No problem                           | "Thanks for fixing that!" → "np 👍"      |
| Chat       | **omw**        | On my way                            | "omw to the office 🚗💨"                  |
| Chat       | **ttyl**       | Talk to you later                    | "Got to run, ttyl!"                      |
| Chat       | **ty / thx**   | Thank you / Thanks                   | "ty for the help!"                       |
| Chat       | **wtf**        | Why the face?                        | "The server's down again?" → "wtf 😕"    |
